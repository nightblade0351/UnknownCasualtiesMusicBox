# 未知伤亡音乐盒 · 命名规则（给 AI 的作业说明）

本文档描述「未知伤亡音乐盒」模组的 `data` 目录规范。**只要按本规则命名文件，模组即可自动识别全部事件音乐。**

---

## 1. 目录结构

```
<游戏>\BepInEx\plugins\UnknownCasualtiesMusicBox\data\
├─ 音乐盒A\            ← 文件夹名 = 设置里显示的音乐盒名称
│   ├─ hall.mp3
│   ├─ choose_part.mp3
│   └─ ...
├─ 音乐盒B\
│   └─ ...
```

**硬性规则**

| 项 | 说明 |
|---|---|
| 一层深度 | `data\<音乐盒名>\<文件>`，不支持再嵌套子文件夹 |
| 文件夹名 = 选项名 | 设置下拉里显示的就是文件夹名本身，不支持别名/本地化 |
| 唯一性 | 同名（忽略大小写）只取一个；冲突会打日志并忽略 |
| 非法字符 | 含 `Path.GetInvalidFileNameChars()` 的文件夹会被忽略 |
| 名称自定 | 中文、空格、`&`、`-`、括号都可以，例如 `理由-CS2新音乐盒（Rad Cat）` |

---

## 2. 文件命名表（核心）

每个事件对应一个**固定基础名**（不含扩展名），大小写不敏感：

| 事件语义 | 基础文件名 | 循环 | 说明 |
|---|---|---|---|
| 大厅 / 主菜单 | `hall` | 循环 | CS 音乐盒的「主界面」 |
| 角色选择 / 交易 | `choose_part` | 循环 | 「队伍选择 / 交易界面」 |
| 加载地图（第 1 层） | `waiting_map_1` | 不循环 | 「行动开始」 |
| 加载地图（第 2 层） | `waiting_map_2` | 不循环 | 「回合开始」 |
| 加载地图（第 3 层） | `waiting_map_3` | 不循环 | 可选，缺省回退 `waiting_map_2` |
| 加载地图（第 4 层及以后） | `waiting_map_4` | 不循环 | 可选，缺省逐级回退 |
| 进入地图（比赛开始） | `in_map` | 不循环 | 层标题窗口出现后播放 |
| 攻击 / 受伤 | `attack_hurt` | 循环 | CS「炸弹安放」 |
| 濒死 / 辐射线 | `articulos` | 循环 | CS「炸弹十秒倒计时」 |
| 暂停 / 比赛结束 | `suspend` | 循环 | CS「比赛结束」 |
| 死亡 / 死亡视角 | `die` | 不循环 | CS「死亡视角」 |
| 结局 1（失败） | `final_result_1` | 不循环 | CS「回合失败」 |
| 结局 2（胜利） | `final_result_2` | 不循环 | CS「回合胜利」 |
| 结局 3 / MVP | `final_result_3` | 不循环 | CS「MVP」 |

> 完整 11 个事件、12 个设置项。`waiting_map_1..4` 共用同一个设置项「加载地图界面音乐」。

## 3. 支持的音频格式与优先级

同一基础名存在多种格式时，按下面顺序取第一个：

```
.mp3  >  .wav  >  .ogg
```

- **不支持 `.flac`**（Unity 2022 与该游戏的加载器都没有 FLAC 解码器）。遇到 `.flac` 会记日志并回退游戏默认，请先转成 mp3。
- 采样率/位深无限制，模组交给 Unity 解码。

---

## 4. 分段（同一事件多首随机）

CS 音乐盒常把一个事件拆成 2 段（如「行动开始-1 / -2」）。本模组用**下划线数字后缀**表示分段：

```
waiting_map_1_1.mp3
waiting_map_1_2.mp3
```

规则：

1. 若存在 `waiting_map_1.mp3`（无后缀主文件），**优先用它**，分段被忽略。
2. 若主文件不存在但存在 `waiting_map_1_*.mp3`，则**随机选一个**播放，日志会打印「分段命中」。
3. 后缀必须是纯数字，`_a`、`_final` 之类不算分段。
4. 大事件同理：`final_result_3_1.mp3` / `final_result_3_2.mp3`。

> 注意 `waiting_map_1_1` 属于 `waiting_map_1` 的分段，不会被误判成 `waiting_map_2`。

---

## 5. 容错规则（模组会自动处理）

| 情况 | 行为 |
|---|---|
| 文件名多一个空格（`waiting_map_1 .mp3`） | 自动宽松匹配并记录日志 |
| 大小写不同（`Hall.MP3`） | 自动匹配 |
| 某事件缺文件 | 该事件回退**游戏原版音乐**，日志记录一次，不影响其它事件 |
| 缺 `waiting_map_3/4` | 逐级回退到 `waiting_map_2`，再回退 `waiting_map_1` |
| 整个音乐盒缺失 | 回退「游戏默认」，配置保留，文件夹放回即恢复 |

### 一键重命名（PowerShell）

把素材文件夹里的文件按上表改名，输出到 mod 的 `data\<音乐盒名>\`：

```powershell
$src  = 'D:\Downloads\理由-Rad Cat'
$dest = 'D:\Application\游戏\Casualties Unknown V1.0.2\BepInEx\plugins\UnknownCasualtiesMusicBox\data\理由-Rad Cat'
New-Item -ItemType Directory -Force -Path $dest | Out-Null

# 原始序号 -> 目标基础名
$map = @{
  1='hall'; 2='final_result_3'; 3='suspend'; 4='in_map'; 5='choose_part'
  6='waiting_map_2_1'; 7='waiting_map_2_2'; 8='final_result_2'; 9='final_result_1'
  10='articulos'; 11='die'; 12='waiting_map_1_1'; 13='waiting_map_1_2'
  14='attack_hurt'; 15='articulos_2'
}

Get-ChildItem $src -File -Filter *.mp3 | ForEach-Object {
    # 只取第一个「1~2 位数字 + 点」作为序号，避开 “CS2”“Av1450263065” 这类噪声
    if ($_.Name -match '(\d{1,2})\.') {
        $idx = [int]$Matches[1]
        if ($map.ContainsKey($idx)) {
            Copy-Item $_.FullName (Join-Path $dest ($map[$idx] + '.mp3')) -Force
        }
    }
}
Get-ChildItem $dest | Select-Object Name, Length
```

## 7. 检查清单（交付前自查）

- [ ] 文件夹名 = 想显示的音乐盒名，且不与已有文件夹重名（忽略大小写）。
- [ ] 11 个基础名齐全：`hall` / `choose_part` / `waiting_map_1` / `waiting_map_2` / `in_map` / `attack_hurt` / `articulos` / `suspend` / `die` / `final_result_1` / `final_result_2` / `final_result_3`。
- [ ] 全部为 `.mp3` / `.wav` / `.ogg`，没有 `.flac`。
- [ ] 文件名无前后空格、无全角字符。
- [ ] 多段用 `_1` `_2` 纯数字后缀。
- [ ] 进入游戏 → 设置 → 音频 → 选择该音乐盒，日志出现 `音乐盒“X”文件检查：11/11 个事件可用`。

## 8. 常见错误

| 现象 | 原因 |
|---|---|
| 选完没声音，日志「11 个事件可用」但没播 | 游戏音量/音乐音量滑条为 0 |
| 某个事件放原版 | 该事件文件缺失（日志 `事件音频不可用`） |
| 音乐盒列表里没有新文件夹 | 未重启游戏（扫描只在启动时进行） |
| 两个音乐盒只显示一个 | 文件夹名仅大小写不同 |
| 分段不随机 | 同时存在无后缀主文件，主文件优先 |
