## 修复

1. **刚进图时“进入地图音乐”被战斗音乐顶掉**：进图瞬间（入水、边缘敌人、辐射读数）会误触发 `attack_hurt`，其优先级高于 `in_map`，导致刚播就被打断。现在给 `in_map` 8 秒独占期，期间战斗/濒死类事件不会抢；8 秒后照常接管。
2. **联机未开主机时，点“开始冒险”仍会播放加载音乐**：原来加载音乐挂在 `PreRunScript.StartRun` 上，而联机模组未开主机时 `StartRun` 仍会被调用并被拦下。现改为由“加载界面出现”的边沿触发，界面没出现就不会响。
3. **`attack_hurt` 触发原因不可见**：新增节流日志，直接标注来源——`刚受伤` / `原版威胁音乐(threat=x)` / `疼痛骤增(pain=x)` / `地震(x)`，便于定位误触发。
